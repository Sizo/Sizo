## How my engineering focus has evolved

**Foundations → working with others.** University work, including the [COS301 capstone fork](https://github.com/Sizo/COS301-Capstone), records an earlier stage of collaborative development and branch-based integration.

**APIs → domain behaviour.** Later Java projects move into service boundaries, validation, external integrations and explicit API contracts.

**Implementation → technical direction.** My focus now extends to explaining trade-offs, making failure behaviour deliberate and keeping designs understandable enough to review, operate and evolve.

## Principles I work toward

- Start with the problem and the simplest design that meets it.
- Make contracts and business rules explicit.
- Treat tests, documentation and operability as part of delivery.
- Leave decisions clear enough for the next engineer to challenge or extend.

These repositories are a record of learning and experimentation. They show different stages of my approach, rather than a claim that every project is production-ready.
